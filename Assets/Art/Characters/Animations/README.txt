Recommended Unity import:

- Filter Mode: Point (no filter)
- Compression: None

For animation clips:
Create Idle, Run, Jump, Fall, Hurt clips from the matching folder.
Use the existing PlayerAnimationController where possible.
Do not replace PlayerController, PlayerHealth, PlayerCombat, checkpoint, goal, pause, or level progression systems.

Note:
These frames are extracted from a presentation sheet, so some poses may need small alignment/art cleanup before final shipping.
